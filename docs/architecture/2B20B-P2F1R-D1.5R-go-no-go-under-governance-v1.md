## 4. Authority ruling

The authorities are non-interchangeable:

1. **Profile Artifact Authority**: the immutable approved profile artifact
   record present in P. It owns topology and obligation data.
2. **Registry Metadata Authority**: the closed metadata record and exact
   selector mapping in `scripts/coverage-profile-registry.mjs`. It references
   the artifact by identity and does not duplicate the full artifact.
3. **Evidence Authority**: E's docs/evidence archive. It records direct P and
   artifact evidence but cannot select, mutate, or reinterpret a profile.

The registry is not product runtime authority, BOTC rule authority, coverage
capture output, or acceptance evidence. A digest proves bytes, not acceptance.

## 6. Reachability and stop state

```text
S=historical registry + source/routing baseline + old selector
P=S + one profile artifact + one metadata record + one exact selector switch
E=P + docs/evidence only
```

S contains no future profile or future SHA. P knows actual S but not E. E knows
actual P but never E. The model has no backward write, dynamic registration,
fallback, second registry file, or E-owned artifact.

The governance stop conditions remain active. Any implementation need for
source parsing, a second registry file, dynamic registration, fallback/latest,
product/test changes, workflow expansion, a permanent migration framework,
E artifact authority, historical-profile rewriting, broken S-to-P-to-E
ancestry, or non-convergent complexity changes the verdict to a stop and
requires new authority.
