## 6. Commit topology, reslice authority, and no self-reference

Let B be the exact materialized design HEAD reviewed before implementation.
Require `parent(S)=B`, `parent(P)=S`, and `parent(E)=P`; each is a
single-parent non-merge commit.

- B predicts no future commit ID.

setup/temp output. A failed S/P/E remains unaccepted evidence; any replacement
requires separately authorized repair and is created from the same
predecessor, never by amend, reset, rebase, force-move, or history rewrite. A
commit after exact-E audit/review invalidates those bindings. Temp artifacts
are deleted only after E archives all required preimages and their hashes are
reverified. Tracked verifier cleanup is later separately authorized scope.

the initial exact-S attempt is interrupted before a complete result by a
recorded `CI_TEST_INFRASTRUCTURE_FAILURE` or
`CI_EXTERNAL_RUNNER_FAILURE`. It must use the same S and unchanged
configuration, tests, dependencies, workers, and timeouts; start from a new
empty evidence root; and reuse no partial artifact. Assertions and
deterministic failures have zero retry. No third attempt exists.

Implementation repair remains separately bounded `0/2`. It cannot disguise a
deterministic failure as infrastructure, create an extra coverage attempt, or
create Implementation Repair Round 3.
